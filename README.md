# NETFORGE v1.0
Developed by Md. Ahsanul Kabir
### Windows Network Diagnostic & Troubleshooting Toolkit

NETFORGE is a lightweight Windows-based network diagnostic and troubleshooting toolkit built with PowerShell.

It provides a simple graphical interface for performing common network administration, diagnostics, configuration, discovery, and repair tasks without requiring users to remember multiple Windows networking commands.

---

## 🚀 Features

### 🌐 Network Discovery
- Discover active devices on the local network
- Automatically detect the local IPv4 network
- Scan a manually specified IP range
- Display discovered/online hosts
- View basic network information

### 🔧 IPv4 Configuration
Configure a network adapter directly from NETFORGE:

- IPv4 Address
- Subnet Prefix
- Default Gateway
- Preferred DNS
- Alternate DNS
- Static IPv4 configuration

Example:

```text
IPv4 Address : 192.168.2.150
Prefix       : 24
Gateway      : 192.168.2.1
DNS 1        : 8.8.8.8
DNS 2        : 1.1.1.1
